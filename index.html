DMS Developer Network

Three UI options

Same ten screens, same mock data, same Arabic/English switch. Each option has its own layout, typeface and palette, and each has a dark and a light theme.

Option 1 · dark by default

Pillar Bar

Top navigation with four colour-coded pillars and a sub-menu. Hairlines, blue accent, Inter.

  • Reads as a developer product site
  • Strong public landing page
  • Sub-menu adds a second row on inner pages
Option 2 · dark by default

Spectrum

Black and white with the four logo colours as one gradient signature. Dropdown menus, bento home, Geist.

  • Most premium, brand-forward look
  • Menus show every screen with a description
  • Colour is used sparingly, so pillars are less coded
Option 3 · light by default

Open Studio

Floating pill navigation, centred search-first home, soft tinted pillar tiles, green accent, Manrope.

  • Friendliest for non-developers and partners
  • Each section gets its own colour wash
  • Roomier, so less fits on one screen

All data is placeholder. Nothing is saved or sent anywhere. Feature list and open questions: PROJECT_ANALYSIS.md in the parent folder.
